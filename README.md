EMBERLINE — a Counter-Strike-style tactical FPS built with three.js. You lead the Vanguard team (you + 2 bots) against 4 Sentinel bots on the Foundry Yard map: plant the charge at the Reactor or eliminate the enemy team. First to 5 rounds wins the match. Four weapons, a frag grenade, plate armour, and a buy phase with money earned per round, kill, and plant. Bots patrol lanes, hold the site, hunt gunshots, and plant/defuse.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser with WebGL 2.
